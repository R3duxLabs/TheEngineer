# The Engineer - App Store Information

This document contains information needed for app store listings.

## App Store Description

### Short Description (30 words)
The Engineer is an advanced Claude-powered AI assistant for software development, data analysis, creative writing, and technical problem-solving with customizable agent personalities.

### Long Description
**The Engineer - Your Advanced AI Assistant**

The Engineer transforms how you work with Claude AI, offering specialized agents for different tasks in a sleek desktop environment. Whether you're coding, analyzing data, writing content, or solving technical problems, The Engineer enhances your productivity with domain-specific expertise.

**Key Features:**

• **Specialized Agent Personalities** - Switch between different Claude agents optimized for specific tasks:
  - Code Expert for software development and debugging
  - Data Scientist for data analysis and visualization
  - Creative Writer for content creation and storytelling
  - Security Expert for cybersecurity analysis
  - Default Claude for general assistance

• **Customizable System Prompts** - Create and save your own agent personalities with custom system prompts, specialties, and behavior parameters.

• **Dark Mode Support** - Work comfortably day or night with automatic or manual theme switching.

• **Offline Capabilities** - Access cached responses and continue working even when disconnected.

• **Conversation Management** - Save, search, export, and import conversations in multiple formats.

• **File System Access** - Analyze and work with local files and projects from within the app.

• **Advanced Settings** - Customize the app's behavior to match your workflow.

The Engineer is the perfect companion for developers, data scientists, content creators, and anyone who wants to leverage Claude's capabilities more effectively.
